# 🌐 Vortex Browser (Windows)

Versão do navegador Vortex para Windows - esta versão foi criada exclusivamente para que usuários de Windows possam testar o navegador sem precisar entrar no Linux ou lidar com Python, etc. Tentei deixar tudo o mais simples possível; infelizmente, o Windows não permite que programas façam automação por questões de segurança, então tive algumas limitações, mas fiz o melhor que pude por enquanto :) abaixo está uma explicação do que você precisa fazer para usá-lo no Windows

---

### 📥 Como baixar e abrir

1. Olhe aqui no canto direito da tela e clique em **Releases**.
2. Baixe o arquivo **`Vortex-Windows.zip`** na lista de arquivos.
3. Vá na sua pasta de Downloads, clique com o botão direito no `.zip` e escolha **"Extrair Tudo..."**.
4. Abra a pasta que foi criada e dê dois cliques em **`main.exe`**.

---

### ⚠️ O Windows bloqueou a abertura?

Como o programa ainda é independente e não tem assinatura paga da Microsoft, o Windows Defender pode mostrar uma tela azul de aviso na primeira vez. É normal:

1. Clique em **"Mais informações"** (texto pequeno logo abaixo do aviso).
2. Clique no botão **"Executar assim mesmo"** que vai aparecer embaixo.
